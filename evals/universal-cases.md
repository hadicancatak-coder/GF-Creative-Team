# Universal eval cases — domain-agnostic failure classes

Give the agent the case input with **no hint about what to look for**; PASS means it raises the expected
catch unprompted. Re-run after ANY brief edit.

The **Outcome** column is the honest record. `MISSED` means a human found it and a gate did not — those
rows are why the rules above them are worded the way they are. Rows marked *codified* came from an
operating or compliance rule rather than a recorded gate failure; they are labelled so you can tell the
difference between evidence and policy.

| U43 | Asked for an ad, the team returns a requirements document — every escape hatch points at stop, and none says "build the best you can and flag the rest" | Deliver, then object. | U44 | A non-building role produces the deliverable itself — the copywriter renders the artwork with a script — because role separation exists only as prose in a brief | Boundaries must be enforced by tooling, not asked for. | U45 | Copy is written before the concept exists, so the headline defaults to a specification — "Up to 65 km of range." — instead of a hook | The idea precedes the words. | U46 | The CTA is set as bare text, so nothing in the frame reads as tappable | A CTA is a button, not a sentence. If the accent colour is spent elsewhere, change the fill — never drop the shape. A viewer who perceives no affordance perceives no offer | designer, art-director | CAUGHT by the repo owner — the built creative's CTA was indistinguishable from a caption |
| U47 | A large empty band is defended in the notes as "composed emptiness" | Composed space is bounded by content on two sides and is doing work. Hard cap: no single empty region above ~20% of canvas. Past that the composition is not using its space, whatever the notes call it | designer, art-director | CAUGHT by the repo owner — 26% of the frame was empty and defended as a deliberate air block |
| U48 | A font is confirmed installed on the build machine and turns out to be absent from the environment that actually renders | "Verified installed" means nothing unless verified where it renders. Figma's font environment is separate from the OS; check there, or the whole set is typeset in a substitute nobody approved | designer, design-analyst | CAUGHT on the fifth live run — Helvetica Neue is on the machine and absent from Figma's 8,930 Google-only faces |
| U49 | A pipeline is optimised for thoroughness with no fast path, so producing one draft costs twenty minutes and nobody uses it | Match depth to intent. A first look needs 2 dispatches, not 5 — merge roles for speed, state the trade, and let the gate (which parallelises) restore quality. An unused correct pipeline beats nothing by nothing | orchestration engine, financial-controller | CAUGHT by the repo owner — "nobody would wait 20 mins for one ad" |
| U50 | A review gate is built for the highest-stakes case and offered as the only option, so a routine spot-check costs 14 dispatches and an hour | Match the gate to the stakes. Most reviews are a checklist against two renders; cross-checking roles and fix rounds are for work that ships. A gate too expensive to run routinely gets skipped routinely | orchestration engine, financial-controller | CAUGHT by the repo owner — the first full gate run cost 1.7M tokens and 60 minutes |
| U51 | Code is edited and pushed, then tested — but the runtime loads an installed copy, so every run exercises the old version and the results are attributed to the new one | Verify the running artifact is the one you changed. ## Scoring
A team revision passes when every case is caught by the named agent without hints. A case that used to
pass and now fails is a **regression** — a brief edit removed something load-bearing. Record it.

## The metric
Track the ratio of `MISSED` to `CAUGHT` over time. Falling means the briefs are learning.
